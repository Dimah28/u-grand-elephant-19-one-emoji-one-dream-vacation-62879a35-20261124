A deterministic program that writes one emoji for a dream vacation to `/output/entry.txt`.

> 🗻 Mount Fuji — a mountain and a faraway place at once, the postcard of one particular dream trip: Japan.

## Run it

```sh
python3 main.py
```

The program writes the emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3.13 standard library only — no network, no randomness, same bytes on every run.
